# COPILOT NOTES

## Prompt Used

I asked GitHub Copilot to generate a professional GitHub Profile README using my actual background, projects, skills, achievements, and experience. I requested a concise, recruiter-friendly README with a tech stack table, featured projects, GitHub stats, badges, and contact information, while explicitly instructing Copilot not to invent skills, projects, or achievements.

## What Copilot Got Right

Copilot generated a clean README structure with sections for my introduction, current work, tech stack, projects, achievements, GitHub statistics, and contact information. It also suggested useful GitHub Stats cards and Shields.io badges.

## What Copilot Got Wrong

Copilot included a broken GitHub repository badge and produced a few generic headings that I improved. I reformatted the tech stack into a proper Markdown table, verified the badge URLs, added my LinkedIn and email, and ensured every project, skill, and achievement matched my resume.
